# About course

This course was inspired by Samsung's **Big Data** educational program, particularly its structured approach to teaching big data technologies through hands-on laboratory work. However, it does not use or reproduce any of Samsung's proprietary materials, code, or documentation; instead, the curriculum has been independently developed to align with modern software versions and the specific infrastructure available to our students.

Matherials:
- HDFS and Yarn - [lab in Russian](ru/HDFS_YARN.md)
- Flume - [lab in Russian](ru/Flume.md)
