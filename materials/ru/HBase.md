## Доступ к данным с помощью HBase

В этой лабораторной работе выполняются базовые операции с созданием, удалением и изменением таблицы в оболочке HBase. Вы будете использовать оболочку для размещения и получения данных в HBase.

---

### 1. Запуск оболочки HBase

**1.1.** Если вы только что вошли в систему, обновите переменные окружения:
```bash
source ~/.bashrc
```

**1.2.** Запустите оболочку HBase:
```bash
hbase shell
```

**1.3.** Выполните команду справки и просмотрите основную информацию об использовании оболочки HBase:
```bash
hbase(main):001:0> help
```
*Примечание: Команды HBase пишутся после символа-приглашения `>`.*

---

### 2. Отображение версии и состояния

**2.1.** Отобразите версию HBase:
```bash
hbase(main):001:0> version
```

**2.2.** Отобразите состояние кластера:
```bash
hbase(main):002:0> status
```
Вы должны увидеть версию HBase и информацию о кластере (например, `1 active master, 0 backup masters, 1 servers`).

---

### 3. Создание и удаление таблиц (DDL)

**3.1.** Используйте команду `create` для создания новой таблицы. Необходимо указать имя таблицы и имя семейства столбцов.
*   Имя таблицы: `tbl_authors`
*   Семейство столбцов (Column Family): `cf1`

```bash
hbase(main):003:0> create 'tbl_authors', 'cf1'
```
*Примечание: Имена таблиц, строки, столбцы должны быть заключены в кавычки.*

**3.2.** Посмотрите список созданных таблиц с помощью команды `list`:
```bash
hbase(main):004:0> list
```

**3.3.** Используйте команду `describe` для просмотра подробных сведений:
```bash
hbase(main):005:0> describe 'tbl_authors'
```

**3.4.** Попробуйте удалить только что созданную таблицу:
```bash
hbase(main):006:0> drop 'tbl_authors'
```
*Примечание: Вы получите ошибку, потому что таблица `tbl_authors` включена (ENABLED). Сначала её нужно отключить.*

**3.5.** Отключите таблицу, а затем удалите её:
```bash
hbase(main):007:0> disable 'tbl_authors'
hbase(main):008:0> drop 'tbl_authors'
hbase(main):009:0> list
```
Убедитесь, что таблица успешно удалена (список должен быть пуст).

---

### 4. Создание тестовой таблицы и вставка данных

**4.1.** Создайте тестовую таблицу `temp` с семейством столбцов `cf1`:
```bash
hbase(main):010:0> create 'temp', 'cf1'
```

**4.2.** Вставьте три значения, по одному за раз, используя команду `put`:
```bash
hbase(main):011:0> put 'temp', 'rk1', 'cf1:a', 'A'
hbase(main):012:0> put 'temp', 'rk2', 'cf1:b', 'B'
hbase(main):013:0> put 'temp', 'rk3', 'cf1:c', 'C'
```

**4.3.** Просмотрите содержимое таблицы с помощью команды `scan`:
```bash
hbase(main):014:0> scan 'temp'
```
Вы должны увидеть три строки (`rk1`, `rk2`, `rk3`) с соответствующими значениями.

**4.4.** Подсчитайте количество строк в таблице `temp`:
```bash
hbase(main):015:0> count 'temp'
```

**4.5.** Добавьте еще значения и проверьте результат:
```bash
hbase(main):016:0> put 'temp', 'rk4', 'cf1:d', 'D'
hbase(main):017:0> put 'temp', 'rk1', 'cf1:b', '1B'
hbase(main):018:0> put 'temp', 'rk5', 'cf1:d', 'E'
hbase(main):019:0> scan 'temp'
```
*Примечание: В таблице теперь 5 строк, но у строки `rk1` есть две версии столбца `cf1:b` (значения `B` и `1B`).*

---

### 5. Изменение атрибутов таблицы

**5.1.** Измените атрибут `VERSIONS` для семейства столбцов `cf1` на 3:
```bash
hbase(main):020:0> alter 'temp', {NAME=>'cf1', VERSIONS=>3}
```

**5.2.** Проверьте, что изменение отражено:
```bash
hbase(main):021:0> desc 'temp'
```
Убедитесь, что в описании семейства `cf1` указано `VERSIONS => '3'`.

---

### 6. Выполнение скрипта команд

**6.1.** Выйдите из оболочки HBase:
```bash
hbase(main):022:0> quit
```

**6.2.** Создайте файл с командами HBase (например, `rubyscript.rb`):
```bash
vi rubyscript.rb
```
Добавьте в него следующие строки:
```ruby
create 'temp', 'cf1'
put 'temp', 'rk1', 'cf1:a', 'A'
put 'temp', 'rk2', 'cf1:b', 'B'
put 'temp', 'rk3', 'cf1:c', 'C'
put 'temp', 'rk4', 'cf1:d', 'D'
alter 'temp', {NAME=>'cf1', VERSIONS=>3}
alter 'temp', 'cf2', 'cf3'
put 'temp', 'rk1', 'cf1:b', '1B'
put 'temp', 'rk5', 'cf1:d', 'E'
scan 'temp'
get 'temp', 'rk1'
count 'temp'
exit
```

**6.3.** Выполните этот файл из оболочки HBase:
```bash
hbase shell
hbase(main):001:0> require './rubyscript.rb'
```

**6.4.** Также можно передавать команды в оболочку HBase в неинтерактивном режиме с помощью команды `echo` и оператора `|` (pipe):
```bash
echo "describe 'temp'" | hbase shell -n
```

### 7. Доступ к данным с помощью команд DML

**7.1.** Запустите оболочку HBase:
```bash
hbase shell
```

**7.2.** Вставьте новое значение для `rk1` в столбец `cf1:b`:
```bash
hbase(main):001:0> put 'temp', 'rk1', 'cf1:b', 'F'
hbase(main):002:0> scan 'temp'
hbase(main):003:0> get 'temp', 'rk1'
```

**7.3.** Получите две предыдущие версии столбца `b` в строке `rk1`:
```bash
hbase(main):004:0> get 'temp', 'rk1', {COLUMNS => 'cf1:b', VERSIONS=>2}
```
*Примечание: Отображаются значения `F` и `1B`.*

**7.4.** Просмотрите всю таблицу, но отобразите только столбцы `a`, `b`, `c`:
```bash
hbase(main):005:0> scan 'temp', {COLUMNS => ['cf1:b', 'cf1:a', 'cf1:c']}
```

**7.5.** Удалите ячейку из столбца `b` для строки `rk1`:
```bash
hbase(main):006:0> delete 'temp', 'rk1', 'cf1:b'
hbase(main):007:0> scan 'temp'
```

**7.6.** Удалите всю строку `rk5`:
```bash
hbase(main):008:0> deleteall 'temp', 'rk5'
hbase(main):009:0> scan 'temp'
```

### 8. Использование MIN_VERSIONS и TTL

**8.1.** Выведите описание таблицы `temp` и проверьте значение TTL для `cf2`. По умолчанию TTL — `FOREVER`:
```bash
hbase(main):010:0> desc 'temp'
```

**8.2.** Измените значение TTL для `cf2` с `FOREVER` на 30 секунд:
```bash
hbase(main):011:0> alter 'temp', NAME => 'cf2', TTL=> 30
hbase(main):012:0> desc 'temp'
```

**8.3.** Вставьте данные в `cf2` с RowKey `rk1`:
```bash
hbase(main):013:0> put 'temp', 'rk1', 'cf2:ttl', 'Y'
hbase(main):014:0> scan 'temp'
```

**8.4.** Подождите не менее 30 секунд и выполните `scan` снова. Строка `cf2:ttl` должна исчезнуть:
```bash
hbase(main):015:0> scan 'temp'
```

**8.5.** Установите TTL на 10 секунд и `MIN_VERSIONS` на 1 для `cf2`:
```bash
hbase(main):016:0> alter 'temp', NAME => 'cf2', TTL=> 10, MIN_VERSIONS => 1
hbase(main):017:0> desc 'temp'
```

**8.6.** Вставьте данные в `cf2` с RowKey `rk5`:
```bash
hbase(main):018:0> put 'temp', 'rk5', 'cf2:ttl_min', 'Z'
```

**8.7.** Подождите не менее 10 секунд и выполните `scan`. Благодаря `MIN_VERSIONS => 1`, значение `Z` должно остаться, даже если TTL истек:
```bash
hbase(main):019:0> scan 'temp'
```

### Самостоятельная работа с HBase

**1. Напишите команду для создания таблицы, отвечающей необходимым требованиям**

**1.1.** Имя таблицы: `movie`
**1.2.** Содержит описание трех фильмов, каждому фильму соответствует столбец.
**1.3.** Все столбцы находятся в семействе `title`.
**1.4.** Названия столбцов соответствуют названиям фильмов (выберите по желанию).
**1.5.** В ячейках таблицы — описание.

```bash
hbase(main):020:0> create 'movie', 'title'
```

**1.6.** Имя таблицы: `ranking`
**1.7.** Содержит информацию об оценках пользователей трех фильмов (фильмы — столбцы).
**1.8.** В ячейках таблицы — оценки.

```bash
hbase(main):021:0> create 'ranking', 'rating'
```

**1.9.** Используйте команду `alter`, чтобы добавить семейство столбцов `fl_title` для названий фильмов на другом языке:
```bash
hbase(main):022:0> alter 'movie', 'fl_title'
```

**1.10.** Убедитесь, что семейство столбцов `fl_title` добавлено:
```bash
hbase(main):023:0> describe 'movie'
```

**2. Напишите команды, отвечающие следующим условиям**

**2.1.** Создайте таблицу `user`:
*   Имя таблицы: `user`
*   Семейство столбцов: `info`
*   Создайте строку с Row key: `rk100`
*   Столбец `age` содержит значение `20`
*   Столбец `gender` содержит значение `F`
*   Столбец `zip` содержит значение `18730`

```bash
hbase(main):024:0> create 'user', 'info'
hbase(main):025:0> put 'user', 'rk100', 'info:age', '20'
hbase(main):026:0> put 'user', 'rk100', 'info:gender', 'F'
hbase(main):027:0> put 'user', 'rk100', 'info:zip', '18730'
```

**2.2.** Отобразите строку с ключом `rk100`:
```bash
hbase(main):028:0> get 'user', 'rk100'
```

Вставьте новые версии столбца `age` для `rk100`:
```bash
hbase(main):029:0> put 'user', 'rk100', 'info:age', '30'
hbase(main):030:0> put 'user', 'rk100', 'info:age', '40'
```

**2.3.** Отобразите строку `rk100` снова. Получите все старые версии столбца `age`:
```bash
hbase(main):031:0> get 'user', 'rk100', {COLUMNS => 'info:age', VERSIONS => 3}
```

**2.4.** Отобразите всю таблицу с помощью `scan`:
```bash
hbase(main):032:0> scan 'user'
```

Удалите столбец `info:age` для строки `rk100`:
```bash
hbase(main):033:0> delete 'user', 'rk100', 'info:age'
```

**2.5.** Убедитесь, что столбец `age` удален:
```bash
hbase(main):034:0> get 'user', 'rk100'
```

Удалите всю строку `rk100`:
```bash
hbase(main):035:0> deleteall 'user', 'rk100'
```

**2.6.** Убедитесь, что строка `rk100` удалена:
```bash
hbase(main):036:0> scan 'user'
```
